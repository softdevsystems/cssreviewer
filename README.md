# TESDA CSS NC II Complete Reviewer — Modules 1–5

A responsive GitHub Pages reviewer reconstructed from the five supplied TESDA Online Program module archives.

## Included

- 5 modules
- 31 lessons
- 303 learning pages after privacy cleanup
- 122 interactive activities
- 230 randomized practice-test questions
- 205 flashcards
- 281 glossary terms
- Responsive desktop, tablet, and mobile interface
- Offline Progressive Web App support
- Local lesson, activity, checklist, and assessment progress
- JSON progress backup and restoration
- Dark mode and print support

## Privacy cleanup

The first printed cover page was removed from every bundled PDF and from every page-image set. The remaining learning pages retain the module content, illustrations, instructions, screenshots, icons, and printed source attributions.

## Important fixes in Version 5

- Matching activities accept selection from either the left or right column.
- Existing pairs can be selected again and changed.
- Pair numbers and distinct borders make matches easier to follow.
- Flashcards now display the term title for all legacy and new card-data formats.
- Flashcards show module and lesson context.
- Added Module 5 with maintenance planning, diagnostics, routine maintenance, defect correction, and inspection/testing activities.
- Improved animations, touch targets, small-screen layouts, sticky mobile activity actions, and reduced-motion support.

## GitHub Pages deployment

1. Extract the ZIP file.
2. Upload the contents of the project folder to the root of a GitHub repository.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub Pages to publish the site.

No PHP, MySQL, or server-side runtime is required.
